# 🚀 Autonomous Chaser Docking Simulation

A MATLAB-based simulation of a 2D autonomous spacecraft (chaser) performing docking maneuvers using PID control, Monte Carlo trials, and physical thruster constraints.

---

## 🛰️ Project Overview

This project simulates the motion of a chaser spacecraft attempting to dock at a fixed target using feedback control. It models real-world spacecraft dynamics including:

- Translational and rotational motion
- PID-based feedback control
- Randomized initial conditions using Monte Carlo simulation
- Thruster force limits and gas consumption
- 2D animated visualization of the docking process

---

## 🔧 Features

- **Monte Carlo Simulation** of chaser initial positions and orientations  
- **PID Control** for both translation and orientation  
- **World-to-Body Frame Force Conversion**  
- **Realistic Constraints**:  
  - Thruster limits (±0.5 N)  
  - Torque constraints  
  - Gas consumption modeled (0.05 g/s)  
-**Trajectory, Velocity, Acceleration, and Energy Profiles**  
-**Animated Visualization**: Shows docking maneuver with orientation and thrust


## Outputs

- **2D Chaser Trajectory**
- **Velocity and Acceleration vs Time**
- **Energy Consumption vs Time**
- **Animated Docking Sequence**
